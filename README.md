## 腾讯云直播解决方案包含哪些产品形态？

包含标准直播、快直播、慢直播、云导播台四种形态，以及移动直播 SDK 和播放器 SDK。它们跑在同一套云端处理链路上，区别主要在延迟、互动方式和适用场景。

标准直播是最常用的形态。主播用 RTMP 推流上云，云端完成转码、录制、截图、鉴黄等处理，观众通过 HTTP-FLV、HLS 等协议观看，延迟通常在 3-10 秒。发布会、活动直播和秀场单向观看大多用它。

快直播对推流和传输链路做了优化，端到端延迟低于 800ms，播放基于 WebRTC，网络波动时优先保证能播，不会让延迟越积越大。

慢直播面向大规模音视频上行，安防监控、景区直播、智慧门店分析是典型用途，云端可以配合录制、时移回看和智能分析。

云导播台负责多路信号的切换与输出，多机位活动、赛事转播会用到。移动直播 SDK 把推流、美颜、连麦、PK、录屏打包成可集成的模块，支持 iOS、Android、PC、微信小程序和 Web/H5 接入。

## 标准直播和快直播的延迟差多少，什么时候值得上快直播？

标准直播延迟 3-10 秒，快直播端到端低于 800ms。是否需要快直播，看业务里有没有等不了的环节：拍卖倒计时、抢购、在线答题、连麦互动、赛事结果，这些场景延迟高了体验直接崩；普通观看型直播，标准直播够用。

## 哪些业务适合，哪些其实用不上？

电商、秀场、在线教育、体育赛事、广电新媒体和企业内部直播是云直播的主要场景。如果只是几十人的内部会议，或者内容以点播回看为主，用实时音视频或云点播更合适，成本和接入复杂度都更低。

电商直播里商品细节展示和实时答疑是刚需，直播把商品信息传递得更完整，能降低营销成本、提升成交。秀场直播看重连麦、PK、美颜特效，移动直播 SDK 里有现成模块。在线教育对版权保护要求高，播放密码、动态 URL 防盗链、DRM 会派上用场，直播录制到云点播后还能给学生回看。体育赛事要低延迟、高清和高并发，快直播负责延迟，4K/8K 和千万级并发能力负责规模和画质。

广电新媒体和赛事转播类似，多机位、高稳定性优先。企业内部培训、年会、发布会更看重安全，防盗链、URL 鉴权、IP 黑白名单、HTTPS 加速这套组合能挡住大部分盗播；服务可用性官方标称 99.9%。

## 接入前要确认的几件事

播放域名必须完成备案，长度不超过 29 位，只能用小写。这是硬门槛，域名不合规，后面的配置都无从谈起。

协议要按终端匹配。推流侧支持 RTMP，也支持 SRT、RTMPS；播放侧支持 HTTP-FLV、HLS、WebRTC，另有 QUIC 协议直播可用于加速。HLS 兼容性最好但延迟高，HTTP-FLV 延迟低、适合大多数 Web 播放，WebRTC 配合快直播使用。

安全配置建议在上线前完成。防盗链、URL 鉴权、IP 黑白名单、HTTPS 安全加速是基础四件套，有版权要求的再加 DRM。内容审核可以接智能鉴黄，减少人工压力。
